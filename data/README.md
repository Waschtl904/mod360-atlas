# Generated data

The complete 360-row atlas is deterministically generated by `exact/generate_atlas.py` as `data/residue-atlas.csv`.

For GitHub browsing, the same 360 rows are also tracked in four stable chunks under `data/residues/`:

- `000-089.csv`
- `090-179.csv`
- `180-269.csv`
- `270-359.csv`

The small summary tables `gcd-strata.csv`, `relation-strata.csv`, and `unit-power-images.json` are generated by the same script.
