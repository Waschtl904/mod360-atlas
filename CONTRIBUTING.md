# Contributing

## Ablauf

1. Issue oder klar beschriebenen Forschungskandidaten anlegen.
2. Einen kleinen, thematisch fokussierten Branch verwenden.
3. Claim-IDs, Statuscodes und Evidenzstufen angeben.
4. Exakte Skripte deterministisch halten und ohne unnötige Abhängigkeiten schreiben.
5. Verifikationsbefehle und erwartete Resultate dokumentieren.
6. Neuheitsbehauptungen nur über `NOVELTY_LEDGER.md` führen.

## Review

Ein Review trennt mindestens: mathematische Korrektheit, Software-Reproduzierbarkeit, Interpretation und Literaturstatus.
