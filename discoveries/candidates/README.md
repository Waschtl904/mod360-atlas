# Entdeckungskandidaten

Jeder Kandidat erhält einen eigenen Unterordner oder eine Markdown-Datei mit:

- vorläufiger Claim-ID
- präziser Aussage
- Entdeckungsdatum und Autor
- Status, normalerweise `NH + ?[O]`
- Datenquelle und Reproduktionsbefehl
- bekannte Gegenbeispielsuche
- geplante Beweisstrategie
- offene Prior-Art-Fragen

Kandidaten dürfen falsch sein. Transparente Widerlegung ist ein erwünschtes Forschungsergebnis.
