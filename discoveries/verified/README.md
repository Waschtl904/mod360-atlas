# Verifizierte Entdeckungen

Ein Eintrag darf hierher verschoben werden, wenn:

- die Aussage präzise und falsifizierbar ist,
- Rechnung oder Beweis reproduziert wurde,
- alle referenzierten Dateien versioniert sind,
- der Status in `CLAIMS.md` aktualisiert wurde,
- Neuheitsstatus und mathematische Gültigkeit getrennt dokumentiert sind.

`verified` bedeutet nicht automatisch `NEW`.
