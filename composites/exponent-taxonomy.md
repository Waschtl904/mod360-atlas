# Composite factorization exponent taxonomy

Let

\[
n=p_1^{e_1}\cdots p_s^{e_s},
\]

where the distinct primes \(p_i>5\). Their residue classes lie in \(G=U(360)\).

The set of all possible residues of this factorization shape is

\[
G^{e_1}\cdots G^{e_s}=G^\delta,
\qquad
\delta=\gcd(e_1,\dots,e_s,12).
\]

Hence only six support sizes occur:

| \(\delta\) | possible unit residues |
|---:|---:|
| 1 | 96 |
| 2 | 6 |
| 3 | 32 |
| 4 | 3 |
| 6 | 2 |
| 12 | 1 |

Examples:

- \(p^2\): 6 residue classes;
- \(p^3\): 32;
- \(p^4\): 3;
- \(p^6\): 2;
- \(p^{12}\equiv1\pmod{360}\);
- \(p^2q^3\): all 96 unit classes are possible;
- \(p^2q^4\): only the six square classes.

The theorem describes **possible residue support** across all choices of primes. It is not a statement of equal natural density for fixed factorization classes.
