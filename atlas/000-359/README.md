# Klassen 000–359

Dieser Ordner ist für klassenspezifische, generierte oder kuratierte Einträge reserviert. Dateinamen sollen dreistellig sein, zum Beispiel `000.md`, `001.md`, …, `359.md`.

Der erste maschinenlesbare Gesamtatlas wird mit folgendem Befehl erzeugt:

```bash
python exact/generate_atlas.py
```

Generierte Dateien sind abgeleitete Artefakte. Manuelle Kommentare müssen klar markiert werden, damit ein erneuter Lauf sie nicht überschreibt.
