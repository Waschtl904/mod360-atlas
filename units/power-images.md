# Unit power images

For \(G=U(360)\cong C_{12}\times C_2^3\),

\[
|G^k|=
\frac{12}{\gcd(12,k)}
\left(\frac{2}{\gcd(2,k)}\right)^3.
\]

Thus \(G^k=G^{\gcd(k,12)}\). For \(k=1,\dots,12\), the image sizes are

\[
96,6,32,3,96,2,96,3,32,6,96,1.
\]

Important images:

\[
G^2=\{1,49,121,169,241,289\}\cong C_6,
\]

\[
G^4=\{1,121,241\}\cong C_3,
\]

\[
G^6=\{1,289\}\cong C_2.
\]

The square map has kernel \(G[2]\cong C_2^4\), size 16, so every square in \(G^2\) has exactly 16 square roots in \(G\).
